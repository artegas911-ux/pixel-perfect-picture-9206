# Pixel Perfect Picture

 # Luxury Automotive Catalog — Single-Page Showcase

A responsive single-page luxury automotive catalog built with **React**, **Vite**, and **Tailwind CSS** as part of a frontend portfolio for **IT-Ausbildung** applications.

🔗 **Live Demo:** https://pixel-perfect-picture-9206.lovable.app

## ✨ Features

- **Wet-Asphalt & Titanium UI:** Dark editorial palette (`#0C0E11`, `#14171D`, `#1C2028`) paired with titanium borders, brushed silver accents, bold motorsport-inspired typography, and tabular price figures (`tabular-nums`).
- **Staggered Entrance & Smooth Motion:** Smooth fade-in and subtle upward motion on initial page load, hover feedback, and accessible `prefers-reduced-motion` support.
- **Expandable Spec Cards:** Six curated luxury vehicles presented in compact spec plates that smoothly expand on click/tap to reveal a concise character description and market price context.
- **Curated 6-Model Lineup:** Porsche 911 (992), Mercedes-Benz S-Class (W223), Range Rover Sport, BMW M5 (G90), Rolls-Royce Cullinan, and Bentley Continental GT.
- **Responsive Layout:** Designed mobile-first for smooth viewing on smartphones, tablets, and desktops.

## 🛠 Tech Stack

- **Framework:** React + TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite

## ℹ️ Disclaimer

This project is a frontend portfolio showcase. Listed prices are approximate average market estimates (depending on model year, mileage, condition, and specification) and do not represent live inventory, real-time valuations, or an active storefront.
